# Job-ready checklist

Tick these off stage by stage. Each line is something you can show or explain in an interview.

## Stage 1: Foundations

- [ ] Advanced SQL (window functions, query tuning) by month 2.
- [ ] 100 or more SQL problems solved, including window functions and reading query plans.
- [ ] You can explain joins, window functions, CTEs and query trade-offs without a memorised script.
- [ ] A Python ETL script that loads API data into Postgres on a cloud VM, with logging and error handling, by month 3.

## Stage 2: Data modelling and the warehouse

- [ ] One star-schema model built in a cloud warehouse free tier.
- [ ] You can model facts, dimensions and common analytics tables.

## Stage 3: Spark, Airflow and the lakehouse

- [ ] One end-to-end Spark, Airflow and dbt lakehouse project by month 7.
- [ ] A PySpark job on 1 GB or more of data, and you can explain its partitioning.
- [ ] An Airflow DAG that schedules a pipeline end to end, with retries.
- [ ] One cloud (AWS or Azure) practised hands-on with its core data services.
- [ ] You can discuss partitions, caching and skew at a beginner interview level.
- [ ] You can build a small pipeline and describe what happens when it fails.

## Stage 4: Streaming, data quality and AI-assisted pipelines

- [ ] Kafka streaming and data-quality tests added to the project by month 10.
- [ ] Cost and design notes in the project README.

## Stage 5: Projects, resume and interviews

- [ ] Two GitHub projects with architecture diagrams and READMEs that explain your design decisions.
- [ ] At most one certification, matched to your cloud: Databricks, AWS or Azure.
- [ ] Your projects turned into honest resume bullets and project stories.
- [ ] Naukri and LinkedIn profiles matched to the keywords of 10 target job descriptions, refreshed weekly.
- [ ] Off-campus applications started from month 8, while you are still learning.

Sources: the checklists on [Data Engineering Roadmap 2026](https://www.prepnplaced.com/data-engineering-roadmap-2026), [How to Become a Data Engineer in India](https://www.prepnplaced.com/how-to-become-data-engineer-india) and [Data Engineer Roadmap](https://www.prepnplaced.com/data-engineer-roadmap).
